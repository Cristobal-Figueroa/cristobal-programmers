# Cristobal Programmers — CSE 325 Group Project

## Project Summary

This repository hosts the semester-long group project for **CSE 325: .NET Software Development** (BYU-Idaho). The team will design and develop a web application using the **.NET / Blazor** technology stack.

The final project will be selected from the proposals below during the next weekly meeting (Wednesdays at 6:00 PM ET).

## Team Members

- Cristobal Figueroa — Group Leader (Week 02)

## Project Proposals

### 1. Inventory & Sales Manager
A web app for small businesses to manage products, stock levels, and daily sales.
- **Features:** product CRUD, low-stock alerts, sales register, daily/weekly sales reports, category filters.
- **Target audience:** small shop owners and family businesses that currently track inventory on paper or spreadsheets.

### 2. Appointment Booking System
A scheduling app for clinics, salons, or independent professionals.
- **Features:** service catalog, calendar view, client booking form, appointment status (pending/confirmed/cancelled), reminder list.
- **Target audience:** health professionals, barbershops, and freelancers who need clients to book time slots online.

### 3. Personal Finance Tracker
A web app to record income and expenses and visualize monthly budgets.
- **Features:** transaction CRUD, expense categories, monthly summaries, budget goals, charts/dashboard.
- **Target audience:** students and young adults who want a simple tool to control spending.
